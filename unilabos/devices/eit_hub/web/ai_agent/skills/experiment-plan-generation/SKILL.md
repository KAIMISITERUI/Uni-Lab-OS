# 实验方案生成

功能:
    为 EIT Hub 生成实验方案时使用. 输出必须面向可执行自动化流程, 不写泛泛的研究建议.

步骤:
1. 明确目标产物, 原料, 溶剂, 催化剂, 温度, 时间, 规模和分析方法.
2. 检查化学品库和知识库中是否已有物质, 危险信息, SOP 或历史实验.
3. 把方案拆成可执行动作, 包括上料, 反应, 后处理, 分析, 数据记录.
4. 对缺失参数明确标记为需要用户确认, 不自行编造.
5. 涉及设备控制时只生成计划和工具参数, 实际执行必须走 control 工具确认.

输出要求:
- 使用简体中文.
- 标点使用英文符号.
- 优先输出表格或编号步骤.
- 包含安全检查和失败处理.
