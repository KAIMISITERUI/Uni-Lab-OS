# 反应模板字段规范

本文件列出 reaction_template.xlsx 中 25 项参数, GC 产率配置和试剂表的全部字段, 取值, 默认值, 单位换算和校验规则. 生成完整 payload 前必读.

> 仅当字段缺失, 模糊, 越界或存在多候选时, 才用 `ask_user_choice` 弹窗询问. 用户已明确给出且符合规则的字段直接采用, 不要重复弹窗确认. 调用范例见 `workflow.md`.

## payload 顶层结构

```
{
  "params": { 25 项参数, 字段名严格按下表 "字段中文名" 列 },
  "headers": [ 试剂表表头, 由系统模板决定 ],
  "rows": [ 试剂表每行, 长度 = headers 长度 ],
  "gc_ms_yield": { GC 产率配置, 含 products 子表 }
}
```

写入前必须先调 `read_reaction_template` 拿到当前 headers 模板. 不得改已有列名. 当反应体系必要成分无空位时, 可以且必须在 headers 末尾追加完整的一组 `试剂`, `试剂量`, 并同步扩展每一行 rows.

## 一. 实验设定

| 字段中文名 | 取值范围 | 默认值 | 备注 |
|---|---|---|---|
| 实验名称 | 字符串 | 必填 | 简短最贴切, 例如 "Suzuki 偶联筛选". 不能为空 |
| 实验ID | 留空 | "" | 上传任务后由系统回填, 模型不要填 |

## 二. 反应设定

| 字段中文名 | 取值范围 | 默认值 | 备注 |
|---|---|---|---|
| 反应规模(mmol) | 0.05 - 0.4 | 0.2 | 超出范围 -> 必须问用户 |
| 反应器类型 | 仅 "heat" | "heat" | 当前只有 heat 这一种 |
| 反应时间(min/h) | 字符串 + 单位 | 必填 | 接受 "30 min", "2 h", "12 h" 等. "过夜" = "12 h" |
| 反应温度(°C) | 0 - 140 | 必填 | "室温" = 25 |
| 转速(rpm) | 0 - 1200 | 500 | |
| 搅拌后目标温度(°C) | 0 - 140 | 25 | 语义: 搅拌结束后到达此温度再进下一步 |
| 等待目标温度 | 是 / 否 | 是 | 默认等待 |

## 三. 称量设定

| 字段中文名 | 取值范围 | 默认值 | 备注 |
|---|---|---|---|
| 称量误差(%) | >=1 | 2 | 称量精度 % |
| 最大称量误差(mg) | >=1 | 1 | 单位 mg |

## 四. 加料设定

| 字段中文名 | 取值范围 | 默认值 | 备注 |
|---|---|---|---|
| 固定加料顺序 | 是 / 否 | 否 | 默认不固定 |
| 自动加磁子 | 是 / 否 | 是 | 默认自动 |

## 五. 稀释设定

稀释液特指反应结束后加入的液体, 不是反应的溶剂. 如果用户只描述反应溶剂, 不要把它填入稀释液字段.

| 字段中文名 | 取值范围 | 默认值 | 备注 |
|---|---|---|---|
| 稀释液种类 | 化学品库中文名 | "" | 留空 = 不稀释. 仅当用户明确描述反应结束后加入的稀释液时填写, 必须 search_chemical 命中 |
| 稀释量(μL) | >0 | "" | 单位 μL. 用户给 mL -> 换算 (×1000). 用户给反应结束后稀释液时必须给量 |

## 六. 内标设定

| 字段中文名 | 取值范围 | 默认值 | 备注 |
|---|---|---|---|
| 内标种类 | 化学品库中文名 | "1,3,5-三异丙基苯" | 改其它必须 search_chemical 命中 |
| 内标用量(μL/mg) | 数值 | 10 (μL) | 默认 10 μL. 单位换算同稀释 |
| 加入内标后搅拌时间(min) | 0 - 60 | 5 | 单位 min |

## 七. 闪滤设定

| 字段中文名 | 取值范围 | 默认值 | 备注 |
|---|---|---|---|
| 闪滤液种类 | 化学品库中文名 | "乙腈" | 改其它必须 search_chemical 命中 |
| 闪滤液用量(μL) | 300 - 600 | 500 | 超范围 -> 问用户 |
| 取样量(μL) | >0 | 2 | 单位 μL |
| 闪滤实验编号 | 字符串 | "" | 留空 = 全部样品. 若填: 必须连续(不可跳号), 数量必须 6 的倍数. 例 "1,2,3,4,5,6" 合法; "1,3,5" 非法; "1,2,3,4,5" 非法 |

## 八. 分析方法设定

| 字段中文名 | 取值范围 | 默认值 | 备注 |
|---|---|---|---|
| GC_MS | 字符串 (方法名) 或 "" | "" | 用户选 GC_MS 时必须填; 必须 list_analysis_methods(instrument="gc_ms") 命中 |
| UPLC_QTOF | 字符串 或 "" | "" | 同上 |
| HPLC | 字符串 或 "" | "" | 同上 |

至少一台分析方法必须填. 用户可同时选多台. 用户明确说 GC 或 GC-MS 时直接映射为 GC_MS; 明确说 UPLC 或 UPLC-QTOF 时直接映射为 UPLC_QTOF; 明确说 HPLC 时直接映射为 HPLC. 已明确且映射唯一时不要再弹分析仪器选择. 各仪器有"实验编号"字段(若 schema 提供), 默认空 = 测全部.

## 九. 试剂表 (rows)

- 行数: 必须是 12, 24, 36, 48 之一. 用户已明确给出这些值时直接采用, 不再弹窗确认. 只有缺失, 模糊或不在允许值中时才询问.
- headers 通常由模板决定, 通常是若干个 "试剂N" + "试剂N用量" + "试剂N单位" 三连列(reagent_pair_count 来自 read_reaction_template). 不得改已有列名.
- 当反应体系必要成分无空位时, 可以且必须在 headers 末尾追加完整的一组 `试剂`, `试剂量`. 追加后必须同步给每一行 rows 追加同样长度的值, 保持 `len(row) == len(headers)`.
- 一般反应体系都需要反应溶剂. 反应溶剂作为试剂表中的一项填写, 不是稀释液. 如果用户未说明反应溶剂, 必须用 ask_user_choice 提醒并询问是否添加. 反应溶剂必须写入试剂表, 不允许因列满而跳过.
- 每个试剂中文名必须 search_chemical 命中.
- 试剂量默认单位 eq. 支持单位: eq, mmol, g, mg, μL, mL.
- 同一行内不同列可以使用不同试剂.
- 缺位列填空字符串. 不要随意删列. 不要输出列满后要求用户自行补表的提示.

## 十. GC 产率配置 (gc_ms_yield)

仅当 `has_gc_ms_yield_sheet=True` 时存在, 由 read_reaction_template 给出.

| 字段 | 默认值 | 备注 |
|---|---|---|
| internal_standard_smiles | "1,3,5-三异丙基苯" 对应 SMILES (CC(C)c1cc(C(C)C)cc(C(C)C)c1) | 内标改其它时必须用户提供 SMILES |
| internal_standard_expected_rt | 6.84 | 单位 min, 默认仅当内标是 1,3,5-三异丙基苯 |
| yield_method | "ECN" | 改其它必须用户给斜率截距等 |
| curve_slope | "" | yield_method != ECN 时必填 |
| curve_intercept | "" | 同上 |
| response_factor | "" | 同上 |
| products | List | 见下 |

products 每项字段:

| 字段 | 默认值 | 备注 |
|---|---|---|
| product_name | 按反应类型(酯化产物 / 缩合产物 / 偶联产物 / Suzuki 产物 / 等) | 必填 |
| smiles | 模型按 product-smiles-rules.md 推断 | 必填 |
| equivalent | 1 | 默认当量 1 |
| expected_rt | "" | 默认空, 用户给则填 |
| applicable_experiments | "" 或 编号串 | 留空 = 全部实验 |

## 必须校验的字段汇总

调 search_chemical: 稀释液种类, 内标种类(非默认时), 闪滤液种类(非默认时), 试剂表每行每个试剂中文名.

调 list_analysis_methods: 用户填的 GC_MS, UPLC_QTOF, HPLC 方法名, 各自查对应仪器命中.

数值范围越界, 单位缺失, 试剂行数不在 {12,24,36,48}, 闪滤编号违反 6 的倍数 / 不连续 -> 一律打断让用户确认, 不允许默认值兜底.
