# ECN 计算方法说明

## 1. 目的

本文档说明 `eit_analysis_station` 当前使用的有效碳数, Effective Carbon Number, ECN 计算方法。

本次实现只覆盖你确认清楚的主表规则, 不包含补充表中的 `P`, `S`, `F`, `Br` 以及其它低清晰度条目。

当前代码入口:

- `eit_analysis_station.processor.ecn.calculate_ecn_from_molecule`
- `eit_analysis_station.processor.yield_calculator.YieldCalculator.calculate_ecn`


## 2. 总体原则

当前 ECN 不再使用旧版“按碳原子邻居字符串猜类别”的方法, 而是改为“按原子局部环境逐原子计分”。

总公式如下:

```text
ECN = 所有命中主表规则的原子贡献值之和
```

这里的“原子贡献”不限于碳原子, 还包括主表中定义了修正值的 `O`, `Cl`, `N` 原子。


## 3. 主表规则

### 3.1 碳原子规则

| 原子 | 化学结构 | ECN |
| --- | --- | --- |
| C | 烷烃类 | 1.0 |
| C | 烯烃 | 0.95 |
| C | 炔烃 | 1.30 |
| C | 羰基 | 0.0 |
| C | 羧基 | 0.032 |
| C | 腈类 | 0.30 |
| C | 芳香烃 | 1.0 |

### 3.2 氧原子规则

| 原子 | 化学结构 | ECN |
| --- | --- | --- |
| O | 醚 | -1.0 |
| O | 伯醇 | -0.60 |
| O | 仲醇 | -0.75 |
| O | 叔醇, 酚 | -0.25 |

### 3.3 氯原子规则

| 原子 | 化学结构 | ECN |
| --- | --- | --- |
| Cl | 一个烷烃碳原子上有两个或更多 | -0.12 |
| Cl | 烯烃碳原子上 | 0.05 |

### 3.4 胺基氮规则

主表原文为“`N 在胺基上, 与对应的醇类似`”。

当前实现按下面的明确口径落地:

| 原子 | 化学结构 | ECN |
| --- | --- | --- |
| N | 一级胺 | -0.60 |
| N | 二级胺 | -0.75 |
| N | 三级胺 | -0.25 |
| N | 苯胺型伯胺, `Ar-NH2` | -0.25 |


## 4. 代码判定口径

### 4.1 碳原子判定优先级

碳原子按下面固定顺序匹配, 命中即停止:

1. 芳香碳: `atom.GetIsAromatic() is True`
2. 腈基碳: 存在 `C#N`
3. 羧基碳: 存在 `C(=O)-O`
4. 羰基碳: 存在 `C=O`, 但不属于羧基碳
5. 炔烃碳: 存在 `C#C`
6. 烯烃碳: 存在非芳香 `C=C`
7. 其余碳: 按烷烃碳处理

这样设计是为了避免旧实现里的误判。例如芳环上连 `O-` 的 ipso 碳仍然是芳香碳, 不会再被误判成羰基碳。

### 4.2 氧原子判定优先级

氧原子按下面固定顺序匹配:

1. 酚氧: 氧上有氢, 且单键连接芳香碳
2. 醇氧: 氧上有氢, 且连接 `sp3` 碳
3. 醚氧: 氧不带氢, 且通过单键连接两个碳
4. 其他氧: 本轮按 `0` 处理

醇的一级, 二级, 三级通过其连接碳的碳邻居数判定:

- `<= 1` 个碳邻居: 伯醇
- `2` 个碳邻居: 仲醇
- `>= 3` 个碳邻居: 叔醇

注:

- 甲醇 `CO` 的羟基氧按伯醇处理
- 酚不作为醇处理
- 羧酸中的 `-OH` 氧本轮不按醇处理

### 4.3 氯原子判定优先级

氯原子只在两种情况下参与计分:

1. 氯连在烯烃碳上: `+0.05`
2. 氯连在饱和碳上, 且该碳带有两个或更多 `Cl`: 每个该类 `Cl` 记 `-0.12`

其余氯原子按 `0` 处理。

### 4.4 胺氮判定口径

只有中性, 单键连接, 且不与羰基碳相连的胺氮参与本轮计分。

具体判定如下:

- 一个碳邻居且至少两个氢: 一级胺
- 两个碳邻居且一个氢: 二级胺
- 三个碳邻居且零个氢: 三级胺
- 若为 `Ar-NH2`, 按苯胺型伯胺 `-0.25`

排除项:

- 酰胺氮
- 亚胺氮
- 芳杂环氮
- 带形式电荷的氮


## 5. 典型样例

### 5.1 乙醇 `CCO`

```text
2 个烷烃碳 = 2 x 1.0 = 2.0
1 个伯醇氧 = -0.60
ECN = 2.0 - 0.60 = 1.40
```

### 5.2 二甲醚 `COC`

```text
2 个烷烃碳 = 2 x 1.0 = 2.0
1 个醚氧 = -1.0
ECN = 2.0 - 1.0 = 1.00
```

### 5.3 苯酚 `Oc1ccccc1`

```text
6 个芳香碳 = 6 x 1.0 = 6.0
1 个酚氧 = -0.25
ECN = 6.0 - 0.25 = 5.75
```

### 5.4 乙腈 `CC#N`

```text
1 个烷烃碳 = 1.0
1 个腈基碳 = 0.30
腈氮本轮不计分
ECN = 1.0 + 0.30 = 1.30
```

### 5.5 二氯甲烷 `ClCCl`

```text
1 个烷烃碳 = 1.0
2 个氯原子, 且都位于同一个带 2 个 Cl 的饱和碳上 = 2 x (-0.12) = -0.24
ECN = 1.0 - 0.24 = 0.76
```

### 5.6 `O=CC1=CC=C(OCOCC)C=C1`

```text
6 个芳香碳 = 6.0
1 个醛基羰基碳 = 0.0
3 个烷烃碳 = 3.0
2 个醚氧 = -2.0
羰基氧本轮 = 0.0
ECN = 6.0 + 0.0 + 3.0 - 2.0 = 7.0
```


## 6. 本次修复的旧 bug

### 6.1 芳环 ipso 碳误判

旧实现用 `CCO` 这类邻居字符串直接判 `ketone`。这会把芳环上连接 `O-` 的 ipso 碳错算成羰基碳。

新实现直接使用 RDKit 的芳香性和键级信息判定, 芳环上的该碳会稳定命中“芳香碳 = 1.0”。

### 6.2 `O-CH2-O` 结构落入 `unknown`

旧实现只会给某些碳分类, 不会把杂原子本身的修正值加进来, 因此 `O-CH2-O` 这类结构常常掉进 `unknown = 0`。

新实现把 `O` 原子作为独立计分对象, 这类结构中的两个醚氧都会按 `-1.0` 参与计算。

### 6.3 小分子含杂原子结果偏差

旧实现对下面这些分子结果明显不合理:

- `CO`
- `COC`
- `CCl`
- `ClCCl`
- `CN`

原因是旧实现几乎只按“碳类别”累计, 没有真正落实主表里的 `O`, `Cl`, `N` 修正规则。


## 7. 暂未实现的规则

本轮没有实现第二张补充表规则, 包括但不限于:

- `P` 相关规则
- `S` 相关规则
- `F`, `Br` 相关补充规则
- 硝基, 酰胺, 腈氮等补充表中的扩展条目

这些规则后续若要加入, 应继续沿用“按原子局部环境逐原子计分”的架构扩展, 不应回退到旧版字符串分类方法。
